# StockFlow

Sistema de gestión de inventario y ventas desarrollado como una aplicación web full-stack.

## Tecnologías

### Backend
- Java 21
- Spring Boot
- Maven
- Spring Security
- JPA / Hibernate

### Frontend
- React
- TypeScript
- Vite

### Base de datos
- MySQL

### Herramientas y DevOps
- Git y GitHub
- Docker (próximamente)
